# Workflow задач на доске

Док описывает пользовательский сценарий для задач на странице доски.

## Создание задачи

В форме создания доступны поля:

- название (обязательно)
- исполнитель (`Не назначено` или пользователь из списка)
- `Выполнить к` (опциональная дата)
- приоритет (`low | medium | high`)
- колонка (`todo | in_progress | done`)
- описание (опционально)

Если исполнитель не выбран, в `owner_label` сохраняется пустое значение и в UI показывается `Не назначено`.
Если дата не выбрана, в `deadline_at` сохраняется `null`.

## Редактирование задачи

В форме редактирования доступны те же поля, что и при создании:

- можно сменить исполнителя
- можно установить, изменить или очистить `Выполнить к`
- можно менять колонку и приоритет

## Перемещение между колонками (DnD)

Используется нативный HTML5 drag-and-drop без внешних библиотек.

- Карточка перетаскивается из одной колонки в другую.
- Внутри колонки порядок вручную не перестраивается.
- При drop обновляются:
  - `status` (целевая колонка)
  - `position` (новая позиция внутри целевой колонки)

После сохранения выполняется повторная загрузка задач выбранной доски.

## Отображение дедлайна

- В карточке задачи и на странице просмотра выводится `Выполнить к`.
- Если `deadline_at` пустой: выводится `Не назначено`.
- Цвет индикации:
  - красный для просроченных
  - зеленый для актуальных (сегодня и позже)
